# Ideal Candidate

A privacy-first PWA that tailors your resume to each job listing using an OpenAI-compatible AI backend (paid API or local Ollama), with honesty levels and local-first encrypted storage.

See `docs/ideal-candidate-buildplan.md` (root) for the full plan.

**Status:** Phase 1 — scaffold, PWA config, encrypted storage, onboarding + honesty level. CI green-gated via GitHub Actions.
