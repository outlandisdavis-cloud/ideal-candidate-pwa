# Launch Checklist (Phase 6)

## Pre-launch
- [ ] Privacy policy + terms drafted and reviewed.
- [ ] Security review: encrypted storage verified, dependency audit clean (`npm audit`).
- [ ] Accessibility audit complete.
- [ ] PWA install + offline flows tested on Android/iOS.

## Web
- [ ] Deploy to hosting (Vercel/Netlify/etc.).
- [ ] Lighthouse PWA score ≥ 90.

## Stores (optional)
- [ ] Google Play (TWA) listing, screenshots, content rating.
- [ ] Apple App Store (Capacitor) listing, privacy nutrition labels.

## Final
- [ ] Version bump + release notes.
- [ ] Announce/launch.
