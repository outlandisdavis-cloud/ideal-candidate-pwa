# Beta Plan (Phase 5)

## Goals
- Validate tailoring quality and UX with real job seekers.
- Catch bugs, accessibility gaps, and privacy issues before launch.

## Recruitment
- 10–20 volunteers from recovery-community or job-search groups (e.g., LinkedIn, local workforce boards).
- Screener: must have a resume and recent job applications; no compensation.

## Feedback channels
- In-app feedback form (local export only, no telemetry).
- Optional email copy of feedback to user’s own mailbox (user-initiated).

## Test focus
- End-to-end flows: onboarding → tailor → save version → track status.
- AI quality: does tailored resume match job requirements without fabrication at default honesty?
- Offline behavior: can users view saved jobs/resumes offline?
- Accessibility: WCAG 2.1 AA check (keyboard nav, contrast, screen-reader labels).

## Exit criteria
- No critical/high bugs open.
- Default-honesty resumes pass manual review for factual accuracy.
- Privacy review complete.
